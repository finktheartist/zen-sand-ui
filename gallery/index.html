Zen Sand UI

Four ordinary controls made of sand that moves like sand. Rake it, push a stone through it, sign your name in it, and watch an AI think in it. Each one is a single file with no dependencies.

The repo on GitHub ↗ @crtvTeknologist on X ↗ @finktheartist on Instagram ↗

The sand is simulated: every groove, heap and ripple is a height field that slumps to its angle of rest, lit on the GPU. Sound plays after your first touch; ZenSand.Sound.on = false turns it off.
